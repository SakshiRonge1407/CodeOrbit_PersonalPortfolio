# Personal Portfolio Website
**Stack:** HTML5, CSS3, vanilla JavaScript. No installation needed.

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Features
- Responsive layout and mobile navigation
- About, skills, projects and contact sections
- Contact form prepares an email in the visitor's mail application
- Semantic HTML and accessible form labels

## Customize
Replace the sample name, biography, projects, and `hello@example.com` with your own truthful details before publishing. This is a demo template; make sure you understand and test it before submitting it as your work.
